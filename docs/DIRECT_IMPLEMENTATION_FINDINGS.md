# Direct-production implementation findings — 2026-09-17

## Verified constraint correction

The common unreduced action contains `b2 * H1 * dot(delta_phi_prime)`.
The old algebraic map formed the H1 source from b3, b4 and b5, omitting b2.
For each radial derivative component, the H1 stationarity equation is

```text
2 L b1 H1 + L v11 delta_A1 + J1 = 0
J1 = b2 dot(delta_phi_prime) + b3 dot(delta_phi)
     + b4 dot(H2) + L b5 dot(h1)
```

`J11[:, 1] += b2` now includes the missing source before the common 2x2
constraint solve. Synthetic nonzero-coupling tests independently substitute the
maps into both H1 and delta_A1 Euler equations at L=6,42,1000. Their residuals
are bounded by 1e-11. This repairs the implemented map without modifying the
frozen action or archived original source. The earlier tests did not check this
stationarity condition.

## Verified emission boundary

The existing `ssz_p5_mh_luminal_g4phi_emitter_JET9D8_2026-09-16.py` explicitly
implements **G4=G4(phi), G4X=0, G5=0** and takes c2 as a supplied profile.
Its emitter does not implement the quartic/quintic action derivatives in the
provided core files. It now rejects nonzero unsupported jets rather than silently
ignoring them. The directly supplied action data have these radial intervals:

| Source | Sampled r/rs interval | Action feature |
| --- | --- | --- |
| Strong carrier | 1.4084507042–1.81316072405 | Luminal G4(phi), G3X |
| G4XX transverse core | 0.01–1.4084507042 | Nonzero G4X, G4XX, mixed jets |
| Full-G5 subcore | 0.003–0.02 | Nonzero G5X as well as quartic jets |
| Center handover | 0.0025–0.012 | Nonzero G4X/G4XX; sampled center transition |

Exact values, columns, file hashes and the locations of the largest unsupported
jets are generated by `python tools/audit_production_sources.py` into
`data/diagnostic/PRODUCTION_SOURCE_CONTRACT.json`.

This is a specific implementation boundary, **not a demonstrated no-go theorem
or a physical instability**. None of the old electric handover slots, historical
reduced matrices, or selected 41-slot tables were relabelled as a global direct
production result. The normal-jet/c2 prescription and quartic/quintic coefficient
terms must be represented in the direct generator before those source profiles
can be used through the same production emitter.

The active, legacy, archived, paper-appendix, prepared-template and JIF versions
of `ssz_p5_zk_appendixA_emitter_JET9D8_2026-09-16.py` were inspected. Before
adding the rejection guard, none referenced `G4XX`, `G5X` or `G5phi`.
They process SVT **f4XX** (lowercase f), not the Horndeski **G4XX** jet.
They explicitly assign `a1 = zeros_like(r)` and `a4 = sqrt(f*h)/2`, with an
Einstein gravitational baseline. Their 41-slot output schema does not imply
support for all Horndeski action terms.

The byte-original legacy emitter SHA-256 is
`fa94b2d147b10c1d697a18431abee6b58143dddcb3a7c040ec0c5e07b8cd45e0`.
The active ZK implementation now rejects unsupported nonzero Horndeski jets;
it cannot silently masquerade as the missing general core emitter. The original
