## Order-of-operations requirement

The radial momentum must not be set to zero before constraint elimination. For dynamic fields q and constrained fields n, the large-L constraint solution has radial background dependence,

    n(r) = -A(r)^(-1) [ C(r) q + D(r) q' + ... ].

Thus q'=0 does not imply n'=0 because n'=C_eff'(r) q can remain nonzero. Background-gradient terms generated by this derivative can contribute to the leading angular principal sector.

Therefore the mandatory order is:

1. Start from the common 41-slot quadratic action.
2. Introduce L = ell(ell+1) as the asymptotic parameter.
3. Assign consistent large-L scalings to dynamic and constrained fields.
4. Solve the constraint equations order-by-order in L, retaining radial derivatives of background-dependent constraint solutions.
5. Substitute the asymptotic constraint solution back into the quadratic action.
6. Only then take the angular/high-L characteristic limit and construct the reduced matrices K_tilde and M_tilde.
7. Solve det(c_Omega^2 K_tilde - M_tilde)=0 with the repository's normalization factors.

Naive k_r=0 pencils formed before this reduction are diagnostic only and may not certify angular propagation.

### D. Mode tracking

Angular modes must be tracked by eigenvector overlap across radius/epsilon, not only by sorting numerical eigenvalues. Avoided crossings must not relabel physical branches silently.
